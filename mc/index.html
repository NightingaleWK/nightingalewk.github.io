膝盖中箭之地

一个 MINECRAFT 游戏群组 · 始于 2017

因为喜欢 Minecraft，也不甘于一个人玩，我在 2017 年开起了服务器。和朋友们一起挖矿、建造、探索，也把一路上的故事留在这里。

就我自己管理，人少事儿少，大家互帮互助，团结友爱。欢迎你们来我家玩，玩~累了直接睡觉，没问题的😘

如何加入

  1. 加入 QQ 审核群 417396863。
  2. 填写入服问卷。
  3. 阅读下方的「玩家守则」，找到文末关键词。
  4. 在审核群里向群主提交关键词和 Java 版或基岩版正版游戏的玩家 ID，注明游戏版本，并 @群主。按自己使用的版本填写，例如：
    • 基岩版：NightingaleWK
    • Java：NightingleWK
  5. 审核通过会拉你进主群并加入白名单，再连接服务器即可。

完整流程见下方「加入方式」。审核需要等待，请耐心一些。
